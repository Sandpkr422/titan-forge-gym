## 🎨 Visual & Aesthetic Features

- **Color System:** Matte charcoal & pitch black base (`#070707`, `#0B0B0B`), electric neon volt accents (`#CCFF00`), and raw electric crimson highlights (`#FF3344`).
- **Typography:** Aggressive condensed headings with **Syne** and **Bebas Neue**, paired with clean **Plus Jakarta Sans** and **Inter** for precision readability.
- **Glassmorphism & Cyber Grids:** Multi-layered blurred panels, subtle cyber-mesh background, animated border-beams, and 3D card tilt effects with dynamic mouse glow tracking.
- **Synthesized Web Audio SFX:** Native Web Audio API sounds for hover, clicks, and pass confirmation fanfares (with full mute/unmute control in the navbar).
